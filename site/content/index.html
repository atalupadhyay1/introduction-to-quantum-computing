QC101 — Quantum Computing & Introduction to Quantum Machine Learning

A complete, interactive study package for the Udemy course QC101 — Introduction to Quantum Computing / Quantum Physics for Beginners by Kumaresan Ramanathan (17 sections, 286 lectures, ~11h 53m).

The course is maths first, and so is this package. Every concept in the course has a matching chapter here and a runnable, auto-graded lab.

How to use this package

# 1. set up (once)
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# 2. run every lab, with an auto-graded pass/fail table
python tools/labcheck.py

# 3. quiz yourself on any section
python tools/quiz.py -s 4

# 4. see how you are doing
python tools/progress.py

# 5. read the study site in your browser
python tools/build_site.py && python -m http.server -d site 8000

The labs are numbered to match the course's sections, and each lab says which course section it belongs to at the top of the file.

Where the material came from

  • The course's own 17-section syllabus and lecture list.
  • The official Packt companion repository — the seven "Course Articles", the Q# project, the Python lab files and the Java simulators.
  • The course's own code, modernized for Qiskit 2.x: BasicAer, QuantumInstance, bind_parameters and qiskit.algorithms.Shor were all removed in Qiskit 1.0, so this package rebuilds those parts.

Nothing here is a summary of the videos; it is a second, runnable implementation of everything the course teaches.
