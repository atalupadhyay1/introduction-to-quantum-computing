A note on accuracy

Every number quoted in this package was produced by running the code in this repository, not by transcribing the course's slides. The labs are auto-graded, and python tools/labcheck.py re-checks all 350 assertions, so if you change a library and break something, the runner will tell you.

The derivations that are not in the course videos but were needed to make the quantum KNN work are written out in chapter 17 and in docs/17-quantum-ml.md.
